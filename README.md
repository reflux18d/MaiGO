使用说明: 
1.编译resource.qrc为resource_rc.py
2.在主文件夹终端内运行cd map
再输入python -m http.server 8000
3.运行logic.py

功能:
a.启动程序，显示主界面，带有按钮“出发”“记录”“设置”“账号”，点击主界面上的立绘人物salt可以互动，会展示文字和语音。
b.点击出发，显示地图，地图上标有机厅的位置，点击对应位置的按钮可以选择本次出勤的目的地，进入本次旅行的界面，会有相应语音提示。
c.在旅行界面里，可以点击按钮“出发”，进入出勤状态，自动开始记录出勤的时间、语音提示，到达目的地后，可以点击到达，进入游玩状态（语音提示），游玩结束后，点击退勤，会停止计时，返回开始界面，并自动记录本次出勤的信息，#可以在开始界面的账号里查看
d.在旅行界面里，可以点击“选项”，选择出勤的交通方式、出装记录等，还可以手动输入记录日记。点击取消放弃更改，点击确定保存。
e.每次出勤界面下方会随机展示不同的tips。
f.在开始界面的“设置”按钮里，可以更改出勤时是否记录交通方式、出装记录等内容，具体反映在旅行界面的选项内容中。
g.点击“记录”按钮，会展示之前出勤的所有记录，点击某次记录的详情按钮，可以看到记录的详细信息
h.点击“账号”按钮，可以看到之前出勤记录的总计信息
i.上述地图、记录、设置界面有返回按钮，返回到上一级

主要文件说明：
logic.py: 项目主体，涉及各个窗口和数据的逻辑，运行该文件启动程序
logicbase.py: 无关ui的基础数据类
subwindow.py: 子窗口类，比如单个日记输入框等
datainfo.py: 具体的出勤记录选项以及tips记录
utils.py: 组长自定义MethodWidget(QWidget), 写了2个快捷操作但是并没有太多应用
ui_class文件夹: 含有由Qt designer生成的各个窗口类文件，用于给logic.py的窗口类完成布局和美化
resources.qrc: Qt designer的资源库文件
requirements.txt: 开发用虚拟环境pip配置
